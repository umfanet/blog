이 문서는 구글 OAuth 앱 「hermes」에 대한 개인정보처리방침이다. 마지막 수정 2026-10-18.

## 무엇인가

hermes는 안주현(umfanet@gmail.com)이 자기 PC에서 혼자 쓰는 개인 비서 도구다. 다른 사람에게 배포하거나 판매하지 않는다.

## 어떤 구글 데이터를 쓰는가

본인 구글 계정에 대해서만, 본인이 승인한 범위 안에서 다음을 읽거나 쓴다.

- Gmail: 메일을 읽고 정리하고, 본인이 요청한 메일을 보낸다.
- 캘린더: 일정을 읽고 만든다.
- 연락처: 읽기만 한다.
- 드라이브·스프레드시트·문서: 본인이 요청한 파일을 읽거나 만든다.

## 어디에 두고, 누구와 나누는가

- 인증 토큰과 데이터는 본인 PC에만 저장한다.
- 작업을 처리하려고 데이터 일부가 본인이 쓰는 AI 서비스(모델 제공자)로 전송될 수 있다. 그 밖의 제3자에게 팔거나 넘기지 않는다.
- 광고나 다른 목적으로 쓰지 않는다.

## 구글 API 데이터 사용 정책 준수

hermes가 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)(제한적 사용 요건 포함)을 따른다.

## 접근 해제

구글 계정의 [타사 연결 관리](https://myaccount.google.com/connections)에서 hermes 접근을 언제든 끊을 수 있다. 끊으면 PC의 토큰도 지운다.
